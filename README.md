# **Workshop: IP Law Meets Open Source Hardware**

**Speakers:** Greta Sparzynski and Tarmio Frei

## **Overview**

This repository provides the slide deck *"IP Law meets Open Source Hardware"*,
presented at Open Hardware Summit 2026 in Berlin on May 24, 2026.

The workshop introduces the role of intellectual property (IP) law in Open
Source Hardware (OSH). It explains how IP rights can both restrict and enable
openness, and how OSH projects can use licensing to support collaboration,
attribution, community trust, and sustainable distribution.

Participants learn how patents, utility models, design rights, trade secrets,
copyright, and trademarks may apply to hardware designs, documentation,
software, logos, physical components, and manufacturing know-how.

## **Topics Covered**

* **Relevance of IP for Open Source Hardware**

* **Patents and Utility Models**

* **Design Rights**

* **Trade Secrets**

* **Copyright**

* **Trademarks**

* **Typical IP Stack in Open Source Hardware**

* **OSH Licensing Models**

* **Permissive, Weak IP Left, and Strong IP Left Licenses**

* **Licensing Obligations and Pitfalls**

## **Learning Outcomes**

Participants understand:

* Why IP rights matter for keeping hardware projects open
* Which IP rights may apply to OSH designs, software, documentation, names,
  logos, and physical components
* How patents, design rights, copyright, trademarks, trade secrets, and utility
  models differ in scope, registration, duration, and strategic use
* How open source licenses use IP rights to grant permission instead of
  excluding others
* How permissive, weak IP left, and strong IP left licensing models affect
  downstream reuse
* Which licensing practices help reduce uncertainty, avoid incompatibility, and
  preserve openness
